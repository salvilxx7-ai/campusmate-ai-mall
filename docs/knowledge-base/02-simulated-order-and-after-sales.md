# CampusMate 模拟订单与售后说明

> **来源与性质说明：** 本文根据公开 C2C 交易规则整理，仅用于 CampusMate 模拟订单演示；系统不处理真实付款、物流、退款或具有法律效力的纠纷裁决。

## 1. 模拟订单的范围

CampusMate 中的订单、价格和状态均为演示数据。创建订单只用于展示“商品预留—个人订单可见—客服按当前用户查询”的业务流程，不会发起扣款、真实配送或真实退款。

## 2. 订单可见性

每笔模拟订单仅对其登录账户可见。客服查询订单时必须先验证当前会话用户；若用户询问他人的订单编号，系统会明确拒绝请求并记录安全审计事件。

## 3. 出现描述不符时怎么办

请先在订单记录中整理商品描述、已披露瑕疵、双方约定和交付情况，并尝试协商。公开 C2C 协议把自主协商与平台调处列为处理争议的常见路径。[1] 当事实不足时，CampusMate 客服只能提供流程指引并转人工，不能认定责任或承诺退款。

## 4. 关于退换与取消

二手交易不应默认存在“签收后无理由退换”。公开争议规范强调已有约定优先，并说明签收后并不当然支持无理由退换，除非存在另行约定或适用特定情形。[2] CampusMate 演示中，任何售后结果都必须以双方记录和人工判断为准。
