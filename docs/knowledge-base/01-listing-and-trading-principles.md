# CampusMate 演示交易与上架原则

> **来源与性质说明：** 本文根据公开 C2C 交易规则整理，仅服务于 CampusMate 项目演示，不是任何学校、闲鱼、Meta 或其他平台的正式制度。遇到校方规定、法律责任或真实付款纠纷，请联系相应人工支持。

## 1. 发布信息应当清楚

上架时应写明物品名称、主要用途、成色、已知瑕疵、是否维修过，以及拟采用的交付方式。若买卖双方针对交付或退换另有明确约定，应在订单沟通中留存；公开二手交易规范也将已有约定视为处理分歧的重要依据。[1]

## 2. CampusMate 演示目录的限制类别

CampusMate 演示目录不展示或支持发布明显违法、侵权或高风险的商品，包括仿冒/盗版内容、危险或需特别许可的物品、动物及动物制品、医疗健康相关商品、已知召回风险商品。公开 Marketplace 规则亦将这些类别列为受限或禁止范围，并提示买卖双方遵守适用法律。[2]

## 3. 交易沟通与自证

为便于演示，商品描述、订单状态和客服问答都应在 CampusMate 内部保留可见记录。客服可以指出已有商品描述或订单状态，但不会替任一方判断法律责任，也不会编造未记录的瑕疵、交付承诺或商品历史。

## 4. 线下交付建议

校园线下交换应在双方同意的安全、公开场所进行。买家应在确认模拟订单前阅读描述，在交付时核对物品状态；卖家应如实回应已知瑕疵。若信息不足，客服会要求补充事实或建议转人工，而不是替双方下结论。
