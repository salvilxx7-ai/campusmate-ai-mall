# CampusMate 性能证据记录

**采样日期：** 2026-08-19  
**采样环境：** 当前开发服务 `http://127.0.0.1:3000`，本地回环网络，服务已启动后连续采样 5 次。

| 路由 | HTTP 状态 | 样本数 | 平均 HTTP 响应时间 |
|---|---:|---:|---:|
| `/` | 200 | 5 | 6.7 ms |
| `/assistant` | 200 | 5 | 3.5 ms |

> 此记录只测量本地开发服务返回 HTML 的 HTTP 时间，不包含真实用户网络、浏览器 JavaScript 下载/解析、字体、图片、客户端渲染或第三方 API 调用。因此它**不能**用于声称“页面加载在 2 秒内”，仅用于证明此版本可重复采集的服务端响应基线。

## 复现命令

```bash
for route in / /assistant; do
  for sample in 1 2 3 4 5; do
    curl -s -o /dev/null -w "$route,$sample,%{http_code},%{time_total}\n" "http://127.0.0.1:3000$route"
  done
done
```

对外简历若需要性能量化，应在指定网络、浏览器、设备与冷/热缓存条件下通过浏览器性能工具采样，并保留原始报告。
